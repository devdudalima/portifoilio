# ✨ Portfólio | Eduarda Lima

Meu portfólio pessoal desenvolvido para apresentar minha trajetória na programação, minhas habilidades e meus projetos.

O projeto reúne minhas experiências de aprendizado e aplicações desenvolvidas durante meus estudos em desenvolvimento web.

## 🌐 Demonstração
🔗 Link para **[Acessar o portfólio](https://devdudalima.github.io/portifoilio/)**

## 📌 Seções do portfólio

- **Início:** apresentação pessoal e introdução ao meu perfil profissional.
- **Formação:** trajetória acadêmica, graduação em Análise e Desenvolvimento de Sistemas e curso Full Stack.
- **Skills:** apresentação das tecnologias e ferramentas que estudo e utilizo.
- **Projetos:** galeria de projetos pessoais, com descrições, tecnologias utilizadas e links para demonstrações e repositórios.
- **Contato:** canais de comunicação para oportunidades profissionais e colaborações.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação das páginas |
| CSS3 | Estilização, layouts e animações |
| JavaScript | Interatividade e funcionalidades |
